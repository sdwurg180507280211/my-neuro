## 🚀 如何使用

### 启动应用
```bash
npm start
```

### 打开商店
点击左下角 **🏪 商店按钮** → 打开插件与角色商店

### 切换角色
点击左下角 **👤 角色按钮** → 选择你喜欢的角色 → 自动切换

## 🎨 界面说明

### 左下角按钮
- 🏪 **商店按钮** - 紫色渐变，打开插件角色商店
- 👤 **角色按钮** - 粉色渐变，打开角色选择面板

### 角色选择面板
- 显示所有可用角色
- 当前使用的角色高亮显示
- 点击即可切换（需要重启）

---

## 🔧 角色切换注意事项

由于 Live2D 模型加载机制，切换角色后**需要重启应用**才能生效。

切换流程：
1. 点击角色按钮打开面板
2. 选择想要的角色
3. 确认切换
4. 重启应用（npm start）

---

## 📊 API 接口（端口 3003）

| 方法 | 路径 | 说明 |
|------|------|------|
| GET | `/market/plugins` | 获取插件列表 |
| POST | `/market/plugins/:id/install` | 安装插件 |
| GET | `/market/characters` | 获取角色列表 |
| POST | `/market/characters/:id/install` | 安装角色 |
